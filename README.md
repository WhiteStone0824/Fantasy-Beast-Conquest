# Fusion Any Monster

Unity 6.4 / URP 2Dで動く、複数ユニット自動戦闘・育成・遺伝子魔法・配合のプロトタイプです。画面はuGUIで実装し、UI Toolkitは使用していません。

## Unityで起動

1. Unity Editorで **Fusion Any Monster > Setup > Create Master Data and UI Demo** を実行します。30系統×7ランクに2種ずつ、計420種の個別種族アセットを含むマスターを作り、TitleとBattleシーンを生成し、Build Settingsの先頭をTitleにします。種族マスターだけ更新する場合は **Fusion Any Monster > Setup > Refresh 420 Species Catalog** を実行します。
2. `Assets/Game/Scenes/Title.unity`を開いてPlayします。
3. ホームから仲間管理・配合・設定を開きます。戦闘開始はホームの「出撃する」だけから行えます。固有魔法は仲間の詳細の「固有魔法を見る」から、その個体に属する情報として確認します。設定画面はセーブと読み込み用です。
4. コード/データ検証は **Fusion Any Monster > Validation > Run Core Checks** から実行できます。

デモセーブは`Application.persistentDataPath/fusion_any_monster_save.json`に保存します。ユニット管理の編成ボタンで最大5体を選べます。全滅で敗北、120秒生存で勝利です。

戦闘中は右上の「捕獲」から敵を仲間にできます。捕獲画面中は一時停止し、敵をクリックして選択します。初期条件はHP35%以下・同じ敵への挑戦1回・1戦で最大3体です。捕獲した仲間は即時保存され、図鑑にも登録されます。[捕獲仕様と設定](Docs/CaptureSystem.md)。

敵を一撃で倒してしまう場合は、対象を選んで「手加減して再開」を使ってください。その敵のHPを1残し、捕獲の機会を作れます。

全420種族に5枠分の初期GP魔法を設定しています。出現した敵は種族ランクに応じて1～5枠を自動使用し、捕獲時にも同じ遺伝子を引き継ぎます。既存の所持個体の魔法は上書きしません。[設定仕様](Docs/SpeciesDefaultMagicRules.md)／[全種族一覧](Docs/SpeciesDefaultMagic.md)。

## 実装済み

- 可変長の型付き魔法プログラム、2本の染色体による発現、部分木交叉・3種類の突然変異、5枠の隠れた魔法遺伝子、自動命名と名前変更を実装しました。新しい配合結果は共通のSpellExecutorで実行し、弾・遅延・分岐・命中/消滅/撃破イベントの構造自体を継承します。初期仲間・既存仲間・配合結果・プレビューをすべてGP方式に統一し、旧形式のデータ項目・実行処理・変換アダプターは削除しました。詳細と起動方法は[固有魔法GP仕様・操作](Docs/SpellProgramming.md)を参照してください。
- 固有魔法の一覧とプレビューに、実際に有効な追加効果（毒・火傷・凍結・麻痺・鈍足・回復・バフなど）を表示します。「効果・詳細を見る」で発動条件・発射方式・弾道・再使用時間と、各効果の付与率・持続時間・具体的な作用を確認できます。デバフの種類と持続時間は実行処理と共通の判定を使います。相手の抵抗によって付与率が下がることを説明し、支援魔法で無効になる攻撃効果は表示しません。
- 全8種類のデバフに持続エフェクトを表示します。毒＝黄緑の泡、火傷＝炎、凍結＝氷晶、麻痺＝稲妻、睡眠＝上昇するZ、鈍足＝足元の輪と下向き矢印、沈黙＝封印マーク、呪い＝紫の周回紋章。敵味方と魔法プレビューで共通の処理を使い、複数のデバフは同時表示します。期限切れ・戦闘終了ではフェードし、戦闘不能では消去します。一時停止中はアニメーションも停止します。表示はキャラクターごとに1つのメッシュを再利用し、最大30fpsで更新します。
- 図鑑と仲間詳細の「2 耐性」は、属性ダメージ軽減・属性による状態異常抵抗・状態異常ごとの抵抗を3列の棒グラフで表示します。全項目0～100%の共通目盛りで、数値は小数点以下切り上げ、中央に50%の目印を付けています。図鑑は「1 種族値／2 耐性」で切り替えます。
- 図鑑の種族値10項目は1列の棒グラフと切り上げた数値で表示します。各能力の表示上限は全種族マスターの最大種族値を切り上げた値で統一し、選択種族や入手状況によって変えません。個体値・レベル・性格・パッシブ補正を含めない、種族そのものの値を表示します。
- 種族図鑑は一度でも仲間にした種族だけ名前・画像・詳細を公開します。未入手は黒いシルエットと「???」で表示し、詳細は開けません。入手履歴をJSONに保存するため、配合で親が消滅しても登録は残ります。旧セーブは現在所持している種族から登録します。履歴導入前に失った種族は過去の入手記録がないため復元できません。
- 全420種に名前と3つの効果を持つ種族共通パッシブを設定しました。[全種族の効果一覧](Docs/SpeciesPassives.md)を参照してください。種族図鑑・仲間詳細の「種族パッシブ」から画像付きで確認でき、戦闘中にも名前を表示します。既存セーブも種族マスターから効果を取得し、配合した子は子の種族のパッシブを持ちます。
- パッシブは属性耐性・属性与ダメージ・属性別MP軽減、能力補正、状態異常抵抗、回復量、毎秒再生、直撃によるHP吸収、瀕死時の攻防、クールダウン・持続時間、命中時の状態異常に対応します。耐性は百分率ポイントを加算して100%で制限し、属性による状態異常抵抗とは分けます。命中時の追加状態異常は毎秒1回まで判定し、MP軽減は最大MPによる補正を行いません。
- 30系統×7ランクに各2種、計420種のSpecies ScriptableObject。旧デモ12種のIDと名前を維持し、種族値・属性耐性・状態異常抵抗は種族マスターとして保持します。
- 30系統に得意能力・苦手能力・属性耐性・状態異常抵抗の傾向を設定しています。天使系は光耐性が高く闇に弱いなど、個別の種族値とパッシブにも違いがあります。[系統ごとの傾向](Docs/SpeciesFamilyTraits.md)。
- IV 0〜100（両端を含む整数）、6性格、レベル1〜99、経験値、能力成長計算、耐性計算の分離。旧セーブの個体値は数値を維持し、0〜100の範囲外だけを補正します。能力計算後のHPは全体で1.5倍されます。通常の敵とボスの基礎HPにも1.5倍を適用します。
- 子の個体値は各能力について両親の平均を中心とする正規分布から決定します。標準偏差は初期値10で、BreedingRuleDatabaseの`ivStandardDeviation`から変更できます。四捨五入して0〜100に収め、配合シードで再現できます。以前の片親選択と個体値の追加突然変異は廃止しました。[計算仕様](Docs/IndividualValueInheritance.md)。
- MagicGenomeの発動/発生/弾道/属性/効果/数値遺伝子、MagicFactoryの範囲補正と複雑度/MP/クールダウン算出。シード可能な交叉・突然変異。
- 戦闘では個体が所持するランク上限内のMagicGenomeを個別クールダウンで巡回発動します。消費MPはMagicFactoryの計算結果をそのまま使い、最大MPによる割引はしません。MP不足の魔法は飛ばして別の使用可能な魔法を調べます。最大MPを超える魔法は現在の能力では発動できず、個体詳細に表示されます。
- 固有魔法は個体の詳細から選び、試射場の映像と属性・威力・消費MPで確認します。威力は魔法自体の基本威力、消費MPは戦闘と同じMagicFactoryで算出した値です。能力値・魔法の数値・耐性の百分率は小数点以下を切り上げ、整数表示します（内部計算・保存値は変更しません）。遺伝子数値・継承／突然変異履歴は非表示で、内部データとセーブには引き続き保持します。
- 魔法プレビューは戦闘と共通の弾道・命中・分裂・範囲攻撃処理を使い、自動で繰り返し再生します。「もう一度見る」で再試射できます。見た目の確認用に発動条件・MP消費を待たずに試射し、個体の育成・所持状態・セーブには影響しません。閉じると専用カメラ・描画テクスチャ・試射用オブジェクトを破棄します。
- 支援用の追加効果遺伝子は「回復」「攻撃強化」「防御強化」「加速」です。いずれかを含む魔法は味方（自分を含む）が対象となり、毒などの敵対効果は実行用パラメータから除外します。元の遺伝子は保持され、交叉で支援効果がなくなれば攻撃魔法にもなります。既存の攻撃遺伝子や所持個体は書き換えません。
- 回復量は基本威力＋術者の魔法攻撃力です。弾は発射数で回復量を分配し、範囲発生は範囲内の味方を回復します。貫通・分裂・命中時の範囲発生も味方だけへ作用します。回復／バフは状態異常付与率・敵対耐性による失敗判定を行いません。
- ApplyBuffノードの強さ `multiplier` は実行時5～50%、持続 `seconds` は実行時1～20秒で、交叉・突然変異・JSON保存に対応します。攻撃強化は物理／魔法ダメージ増加、防御強化は被ダメージ軽減、加速は移動と通常攻撃の頻度増加です。同種は加算・乗算せず強い効果と長い残り時間を採用し、期限切れで元に戻ります。複雑度に応じてMP消費／クールダウンが増えます。
- 支援AIは射程内の生存する味方を選び、回復ではHP割合の低い味方を優先します。ほぼ全快の味方への回復や、十分残っている同等以上のバフを避けます。定期発動なら敵がいなくても使用可能で、敵接近・被ダメージなどの発動条件は維持します。プレビューには練習用の味方・HPバー・支援の発光を表示します。新規ゲームには4種類の支援遺伝子を持つ親を用意し、既存データでも配合の突然変異から取得できます。
- 弾は標的以外も含む進路上の対象へ近い順に命中します。分裂は命中地点から発生し、CastSessionで累計弾数48・生成世代3・イベント128を共有します。直進・追尾・螺旋・波状・周回をノードから実行し、弾寿命は最大6秒、終了時はその場で0.3秒フェードします。旧形式の貫通・連射・ランダム移動は廃止しました。
- 凍結は移動・攻撃を停止、毒/火傷は付与した属性の耐性と魔法防御で軽減されます。HP吸収は実際に与えたダメージの12%、MP吸収は敵から実際に奪った量を回復します。敵にも種族のMP・防御・耐性を反映します。
- 属性別の弾色、発射方式別の弾形状、軌跡、弾のトレイル、着弾リング、アリーナ境界、各味方の魔法名/効果/MP/威力/クールダウン/発動数を戦闘画面に表示します。味方と敵には種族スプライトを割り当てます。
- 全30系統の組み合わせ表（465通り）と独立ランク規則。候補種族の解決、IV/性格/Genome遺伝、生成履歴と系譜。
- 同じ系統同士では、親のうち高い方より1ランク上の子が必ず生まれます（上限S）。同種族同士や異なるランク同士にも適用します。それ以外は親のランク平均に端数がある場合、50%ずつ切り上げ・切り捨て、さらに確率で1ランク上昇します。ランク下降の抽選はありません。対応ランクの種族が未登録なら下位種族で代用せず、配合を成立させません。特殊配合はこれらに優先します。
- 子の系統は親2体の組み合わせ表から決定します。例：精霊系＋物質系＝魔導系、獣系＋機械系＝人工生命系、天使系＋悪魔系＝混沌系。A＋BとB＋Aは同じ結果です。[全465通り](Docs/BreedingFamilyTable.md)／[30×30の早見表CSV](Docs/BreedingFamilyMatrix.csv)。
- 配合表は各結果系統15～16通りに均等化しています。親を固定した場合も結果15～17種類、同じ結果は最大5通りです。代表レシピと系統の関連性を保った固定表です。[偏りの比較](Docs/BreedingFamilyBalance.md)。
- 自動索敵/移動/攻撃、性格差、複数投射、追尾/曲線/螺旋/ランダム/周回弾道、属性軽減、毒/火傷/凍結、HP吸収、爆発、撃破経験値。
- JSON形式の個体/編成/Genome/系譜セーブ。 uGUIのタイトル、個体一覧/詳細、編成、親選択/配合実行、魔法詳細、設定画面。配合画面には結果予測・抽選番号・再抽選ボタンを表示しません。
- 種族図鑑は6列×3行の画像アイコン一覧で、選択すると種族の大きな画像・能力値・耐性を確認できます。編成画面の所持仲間は3列×3行の画像アイコン一覧で、選択中は金枠、出撃編成中は「編成中」バッジを表示します。個体の詳細表示・編成操作・魔法プレビューは従来の導線から利用できます。
- 仲間詳細の1ページ目は最終能力値10項目を1列の棒グラフで表示し、能力ごとに全キャラ共通の固定尺度で長さを比較します。尺度はResources/StatBarScaleSettings.assetで調整できます。キャラ選択・編成・所持数による自動変更はなく、能力値計算や保存値も変更しません。隣には0～100固定目盛りの10角形レーダーチャートで個体値を表示します。2ページ目は属性ダメージ軽減・属性による状態異常抵抗・状態異常ごとの抵抗を分けて表示します。編成操作と魔法詳細は両ページから利用でき、表示を切り替えても個体データは変更しません。
- 配合の親選択も6列×3行の画像アイコン一覧で、親A・親Bのバッジを表示します。もう片方の親に選択済みの個体は選択不可です。配合画面の親枠にも画像を表示し、クリックすると一覧から選び直せます。
- 配合と保存が成功すると、誕生した個体の画像アイコンを結果画面に表示します。アイコンからその子の詳細・固有魔法へ進めます。「続けて配合する」で親選択へ戻れます。失敗時には成功結果を表示しません。
- 戦闘UIはuGUI／TextMesh Proで、生存時間・目標進行バー・ウェーブ・撃破数・戦闘速度、味方の画像とHP／MP、状態異常／バフ、ボスHP、ウェーブ告知を表示します。停止ボタンで一時停止／再開でき、終了結果からホームへ戻れます。「魔法」で各個体の魔法と準備状況を確認できます。
- ダメージ・HP回復・MP回復・状態変化・レベルアップは頭上へ浮かぶ文字で表示します。表示数は最大64、短時間の同種ダメージは合算し、実際に変化した量を切り上げ表示します。プレビューではこの戦闘用HUDを生成しません。
- UI拡大縮小は最小仮想領域1280×720を保つExpand方式です。仲間の画像を枠外へ拡大せず、能力・説明・耐性の表示領域を分けています。文字の見切れ、画像の枠外へのはみ出し、ボタン同士の重なりを960×540・1024×768・1920×1080・2560×1080の18画面で検査しています。
- 複数Spriteへ自動分割された画像は、最初の微小な画像片ではなく最大領域のSpriteを種族画像として登録します。48種の誤参照を修正し、全420種で本体領域を参照することを検査します。PNGの再生成や変更は行っていません。
- 配合成功時は親2体が所持一覧・出撃編成から消滅し、子1体を追加します。親が編成中なら子を1枠へ編成します。親のIDは子の系譜に保持します。保存失敗時は親・編成・親選択を変更せず、成功後は親選択を解除して同じ個体の再使用を防ぎます。
- 開発用のローカルComfyUI API連携コードとワークフローを保持しています。プレイヤー向け設定画面からの画像生成・接続先設定は撤去し、ゲームUIから生成サービスを起動しません。

## ComfyUI

画像生成はローカルComfyUIのみを使います。既定接続先は`http://127.0.0.1:8188`です。`Assets/Game/Art/workflow_api.json`はPony Diffusion V6 XL (`ponyDiffusionV6XL_v6StartWithThisOne.safetensors`) と LayerDiffuse SDXL Conv Injectionを使うAPI workflowで、出力解像度は1024×1024です。420種族それぞれの透明PNGを`Assets/Game/Sprites/Generated/<speciesId>.png`へ生成し、全420種族マスターへSpriteを割り当てています。生成条件は同名の`.generation.json`に保存しました。今後の生成も1024×1024を標準にします。

1. ComfyUI、Ponyチェックポイント、LayerDiffuseノード/重みをローカルに用意して起動します。
2. Unityで **Fusion Any Monster > Setup > Create Master Data and UI Demo** を実行し、`ComfyUISettings`の接続先とworkflowパスを確認します。標準workflowのpromptノードは6/7、seedノードは3です。
3. 画像生成は開発時にComfyUIで行い、生成した画像をUnityへ取り込みます。ゲーム内の設定画面には画像生成機能はありません。

ワークフローがない/生成に失敗した場合はプレースホルダーでゲームを続けます。別サービスへの切替やモデルの自動ダウンロードは行いません。詳細は[Art README](Assets/Game/Runtime/Art/README.md)を参照してください。
