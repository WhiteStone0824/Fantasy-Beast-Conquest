# 系統の配合ルール

親の系統A＋親の系統Bから、子の系統Cを表で決定します。A＋BとB＋Aは同じ子系統になります。既存30系統の465通りに真理系との31通りを加え、31系統・計496通りを定義しています。

- [全465通りの一覧](BreedingFamilyTable.md)
- [30×30の早見表CSV](BreedingFamilyMatrix.csv)
- [465レシピのCSV](BreedingFamilyRecipes.csv)
- [重複・偏りの調整結果](BreedingFamilyBalance.md)

既存30系統同士の465通りでは、各系統が子の系統になる回数を15～16通りに揃えています。真理系の31通りはこの均等化の対象外です。姿・生息環境・素材・霊性などの関連性から候補を絞り、代表レシピと同系統同士の結果を維持しました。各レシピの考え方は一覧とCSVに記載しています。

真理系は特別な祖父母レシピで誕生します。また、この特別な真理系個体を親として配合すると、相手の系統にかかわらず同じ種族の子が生まれます。親は通常どおり消滅し、個体値・性格・魔法遺伝子は両親から継承されます。

これは固定された表の分布です。親の組み合わせを選ぶたびに結果系統を抽選する仕様ではなく、所持している親の偏りによって実際の出現割合は変わります。

指定された「精霊系＋物質系＝魔導系」を採用しました。ほかの組み合わせは、生物同士の融合、機械・生命の融合、精霊による魔力付与、霊体の憑依などを基準にした仮の配合表です。例えば獣＋機械は人工生命、霊体＋物質は呪物、天使＋悪魔は混沌になります。結果が親のどちらかの系統を引き継ぐ組み合わせもあります。

## 他の遺伝処理との関係

この表は系統だけを決めます。子のランク、個体値の正規分布、性格、魔法の部分木・ノード内部の交叉は、それぞれ既存の規則で処理します。

同ランク・同系統・別種族同士なら子を1ランク上げる規則も維持します（SはS）。確定した系統とランクに対応する種族を選びます。同じ系統で近いランクを探す既存の候補補完は維持しますが、結果系統自体が登録されていなければ配合を不成立にします。別の系統で代用することはありません。確定昇格に必要なランクが存在しない場合も、従来どおり不成立です。

## 編集

実際に使う設定は`Assets/Game/Resources/BreedingRuleDatabase.asset`の`familyRules`です。`Assets/Game/Data/Breeding/BreedingRuleDatabase.asset`にも同じ初期表を保存しています。個体値の標準偏差など、他の設定は今回の適用で変更しません。

`FamilyBreedingCatalog`が既定の465レシピを定義します。設定ファイルがない場合や、その組み合わせの行が未設定の場合もこの表を参照し、enum番号の大小では結果を決めません。

`Fusion Any Monster > Breeding > Apply Family Combination Table`は、両方のアセットへ既定表を適用し、上記の一覧とCSVを出力します。この操作は既存のカスタム配合行を既定表へ置き換えます。変更した表を既定値にする場合は、FamilyBreedingCatalogも編集してください。

今回の変更は今後の配合結果に適用します。すでに所持している個体を変更したり、配合を実行して親を消費したりする移行処理はありません。
