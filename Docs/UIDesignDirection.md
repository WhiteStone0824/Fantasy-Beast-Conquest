# UIデザイン方針：夜の探検隊の記録帳

## 世界観と目的

幻想的な夜の遠征拠点を背景に、仲間・種族・配合・戦闘を記録帳のように読み解けるUI。キャラクターの姿と、次にできる操作を主役にする。以後の画面追加・改修でもこの方針を共通の基準とし、既存の画面や操作ルールとの整合を確認する。

## 共通ルール

- 背景には既存の拠点イラストを使い、文字の背後には十分に濃い紺の面を敷く。絵の上に細い文字を直接重ねない。
- 基調は深い紺、本文は明るい白、補足は明るい灰青。金色は見出しと選択中の目印、青緑は主要操作に使う。赤は危険・敵・解除不能な操作に限定する。
- 同じ目的のボタン・カード・枠・余白・強調表示は、画面をまたいで共通の色と形式にする。操作状態は色だけに依存せず、文字や枠でも示す。
- 日本語のTextMesh Proフォントを使用する。説明は短く、重要な操作と状態を先に表示する。長い名前は枠内で読めるようにし、キャラクター画像は全体を表示する。
- ホームには編成中の仲間と出撃操作を明確に配置し、図鑑・編成・配合は画像付きカードを基本とする。出撃とLAN対戦の導線はホームからとする。
- 戦闘では視界を遮らない濃い情報パネルを使い、時間・ウェーブ・HP・MPと勝敗を優先する。装飾は情報より目立たせない。
- 操作不可・選択中・通信中・エラーを見た目と文言で区別し、戻る操作を明示する。背景、キャラクター、グラフの情報は色以外の文字でも確認できるようにする。
- uGUIとTextMesh Proを使い、Unity UI Toolkitは導入しない。画面追加時は既存の共通コンポーネント・色を再利用する。

## 検証

UnityのGameビューでホーム、図鑑、仲間一覧、配合、出撃選択、LAN対戦、戦闘を確認する。16:9に加え異なる画面サイズで文字・ボタン・画像の重なりや切れを確認する。ゲーム状態とセーブを変更する操作の実行結果は、見た目だけの確認と区別する。
