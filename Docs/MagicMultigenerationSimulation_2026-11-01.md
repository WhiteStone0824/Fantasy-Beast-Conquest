# 固有魔法の複数世代配合シミュレーション

## 方法

Unity上で実際の `BreedingSystem.Breed` と種族データを使用。シードは20261101。第1世代は種族の標準魔法を持つ親から300体を生成し、第2～5世代は直前の世代の子から異なる2体をランダムに選び、それぞれ300体を生成した。個体の選択は復元抽出なので、同じ個体が複数の配合の親になることがある。ゲームの「配合した親が消滅する」進行を再現した母集団モデルではなく、遺伝の挙動を調べるための実験である。

全種族を初代の親とする場合と、野生出現6系統の種族を初代の親とする場合を実施。いずれも初代の候補は種族ごとに一様で、出現率やランクには重み付けしていない。第2世代以降は6系統に限定しない。全世代で子はレベル1、装備なし。未解放枠は受け継いだうえで、集計から除外した。祖父母参照の特殊レシピは設定していない。

静的評価は `SpellSemanticAnalyzer` と `SpellViabilityEvaluator` を使用し、条件付きで発動可能な魔法を有効と区別している。対象不一致を含む魔法のうち、別の有効経路があるものは有効・条件付きにも含まれる。代替は当該世代の遺伝履歴に標準魔法への代替が記録された魔法。プレイヤーのセーブは読み書きしない。

## 解釈と制約

この試行では、世代を経ると構造署名・特徴の組み合わせが増加した一方、一部の効果の対象不一致と標準魔法への代替も増加した。ただし、上位ランクの子が増えると使用可能枠数も増えるため、単純な種類数の増加には試料数増加の影響が含まれる。1シードのランダム試行であり、これだけで一般的な傾向を確定できない。

特徴は生成ノードの種類・属性・弾道・対象と、効果種類・状態異常・バフの集合であり、数値差を含まない。構造署名にはノードIDを含む。いずれも実際に異なる有効な挙動の厳密な種類数ではない。

判定は静的な近似であり、戦闘で本当に対象に届くか、適切なタイミングで使用されるか、威力や回復量が役立つかは検証していない。ゼロ件は実戦での無効魔法ゼロを意味しない。実際の捕獲・配合の選択、装備、育成、複数シード、特別配合も未検証。

再実行用のUnity MCP `execute_code` 本文は `Docs/MagicMultigenerationSimulation.cs.txt`。`wildOnly` で親の候補を切り替える。
