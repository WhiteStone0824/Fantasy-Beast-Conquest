# 固有魔法：遺伝的プログラミング

## 実装と起動

Unity 6 / C#。通常の戦闘・配合・JSON保存・魔法プレビューへ統合しています。ビルドは不要です。

1. `Assets/Game/Scenes/Title.unity` をPlayし、配合で新しい魔法プログラムを持つ子を作ります。通常の個体詳細から名前・効果・プレビューを確認できます。
2. 単独で挙動を確認する場合は `Assets/Game/Scenes/SpellProgrammingDemo.unity` を開いてPlayします。追尾爆発・分裂毒・連鎖麻痺の3例をボタンで切り替えます。仲間がAIで自動発動し、検証用の的へ作用します。
3. `Fusion Any Monster > Spells > Genetic Programming Lab` で染色体A/B・発現結果・ノード構造・交叉前JSON・変異履歴を確認できます。乱数シード、ランダム生成、親Bへの複製、配合、突然変異、JSON保存・読込に対応します。
4. Labの「Play中のデモへ反映」で、現在の遺伝子を実際のデモへ渡せます。通常の所持個体やセーブは変更しません。
5. デモと設定を再生成する場合は `Fusion Any Monster > Spells > Create Playable Demo Scene`。既存の制限・命名アセットは上書きしません。

## 遺伝子・表現型・コンパイル結果

- MagicGenome.programGenesに2本の染色体を持つSpellGenotypeを保存します。発現しなかった染色体も残ります。
- MagicGenome.expressedProgramは独立した発現結果の保存スナップショットです。実行時は遺伝子から改めて発現・検証し、保存スナップショットを信用して実行しません。
- CompiledSpellは命令・パラメータ・接続先の配列を保持し、保存しません。戦闘準備・プレビュー初期化時に一度コンパイルします。
- Genotype.version / algorithmVersion / programVersionは現在1。未知のプログラムは実行せず、JSONパース時に拒否します。通常セーブ全体のschemaVersionは2です。
- 発現時のノード数・深さの制約も遺伝子型に保存し、設定変更だけで同じ遺伝子の発現構造が変わらないようにします。現在の実行上限を超える既存プログラムはコンパイル時に拒否します。初期のバージョン1データにこの項目がない場合は24ノード・深さ6として扱います。
- programVersion=1と有効な2本の染色体が必須です。旧形式のJSON、空オブジェクト、不正な木は受け付けません。保存済みの発現結果を信用せず、読み込み時は染色体から再生成します。

## 型付き接続とノード

Cast / Hit / Expire / Killを入力コンテキストとして扱います。Nextは同じ入力型を引き継ぎ、OnHit / OnExpire / OnKillは対応する型の子にしかつながりません。Hitには対象・位置・直前の実ダメージ、Killには撃破対象などを渡します。

トリガーはルートだけです。ノードID重複、存在しない接続先、同一ポートの重複、共有ノード、循環、到達不能ノード、不正な数値・enum、深さやノード数の超過を拒否します。交叉で取り込む部分木は入力型が一致する候補から選び、接続とIDを再構築します。

指定のトリガー・弾/範囲生成・ダメージ/回復/爆発/全8種の状態異常/ノックバック/HP吸収・Delay/RandomBranch/Conditionalを実装しています。既存の支援を維持するため、ApplyBuff、ManaSteal、有限のSequenceも追加しています。Sequenceは枝を一度ずつ実行し、繰り返しノードではありません。

弾道は直進・追尾・螺旋・波状・周回です。SpawnProjectile/SplitProjectileは命中・消滅・撃破の別々の部分木を持てます。SpawnAreaは持続中0.5秒ごとに範囲内の対象へOnHitを発行し、終了時刻にOnExpireを発行します。

弾のOnExpireは寿命・射程の終了時に発行します。命中による消滅はOnHitとして扱います。周期トリガーは基礎クールダウンと指定周期の大きい方へ複雑度補正を適用します。

## 発現・遺伝・突然変異

1. 調節遺伝子のdominanceが高い染色体を基礎にします。同値ならAです。
2. spliceが有効ならrecipientIndex/donorIndexで互換部分木を最大1つ組み込みます。乱数や現在時刻を参照しません。
3. 不正な構造になる組み込みは取り消し、元の基礎染色体を採用します。
4. 配合では親A/Bの対応するスロットからそれぞれ配偶子を作り、子の染色体A/Bとします。
5. 配偶子は親の2本を部分木交叉し、パラメータ・ノード置換・追加/削除/部分木置換を試みます。各変更を個別に検証し、不正なら取り消します。
6. 両親からできた配偶子同士でノード内部を交叉します。親A由来の構造には親B由来の値を、親B由来の構造には親A由来の値を混ぜます。両方とも変更前の配偶子を参照し、一方の交叉結果がもう一方に流れ込まないようにします。

ノード内部の交叉は`SpellParameterCrossover`で行います。

- 種類と入力型が同じノードを対応付けます。同じポート経路のノードを優先し、なければ同種・同入力型の未使用ノードから選びます。対応がないノードは維持します。
- 対応ノードごとに70%（`nodeParameterCrossoverChance`）で交叉を試みます。種類の異なるノードの中身は混ぜません。
- 属性・弾道・状態異常・対象選択・条件・バフ種類・自分中心かどうかは、項目ごとに50%ずつの確率で両親のどちらかから選びます。
- 弾速・角度・持続時間・半径・追尾性能・威力倍率・付与確率・HP閾値は、それぞれ独立したランダムな混合比で両親の値の間を補間します。弾数も混合後に最も近い整数へ丸めます。
- プログラム全体の基礎威力・基本クールダウン・射程も、別途同じ交叉率で判定し、各数値を混合します。全体の対象選択と調節遺伝子は基礎構造のものを維持します。
- ノードID・種類・入力型・接続先を維持し、最後に構造と値を検証します。不正なら、その染色体のノード内部交叉を取り消します。採用した交叉は内部履歴に記録します。

例えば親Aの「火・直進」と親Bの「水・追尾」から、突然変異なしで「火・追尾」が生まれます。親の片方が同じ染色体を2本持っていても、もう片方の親の値と組み合わさります。既存の遺伝子の保存形式と発現アルゴリズムは維持するため、所持魔法は書き換えません。今後の配合結果は新しい交叉処理により変わります。

親のデータはコピーして扱い、書き換えません。交叉と変異はSystem.Randomの明示シードを使用します。個体IDは既存仕様どおりGUIDで、同じ配合の子でもIDそのものは変わります。

## 5枠と既存セーブ

- UnitInstance.magicGeneSlots / UnitSaveData.magicSlotGenomeJsonが常に5枠分の内部遺伝子を保持します。
- magicGenomes / magicGenomeJsonはランクで使用できる枠の表示用データです。F/E=1、D/C=2、B=3、A=4、S=5。
- 子は同じスロット番号同士を継承します。使用できない枠を削除しません。
- 初期仲間を含む全個体がGP形式を使用します。存在しなかった隠し枠だけを個体IDと枠番号から決定論的に補い、ランクに対応する枠を使用可能にします。
- 戦闘・配合・プレビューはGP専用です。旧形式の実行処理と変換アダプターはありません。作業時の既存セーブ変換とバックアップについてはGPOnlyMigration.mdを参照してください。
- 不明/不正な保存済み枠は別の魔法へ置換しません。ロード時に読み取り専用へ切り替えて元ファイルを保護し、保存は拒否します。

## 戦闘AI

新形式の使用可能枠をスロット番号順に個別評価します。MP、独立クールダウン、沈黙、トリガー条件、有効な敵/味方対象を確認して発動し、実際のMP消費・再使用時間を反映します。移動と魔法発動を共通の待ち時間で止めません。

魔法威力・魔法攻撃力・魔法防御・属性耐性・バフ/デバフ・種族パッシブを既存のダメージ/回復処理へ渡します。攻撃効果は敵、回復/バフは味方にだけ適用します。状態異常は既存の耐性と持続エフェクトを使用します。

短射程の攻撃には近づき、範囲外の負傷した味方には支援役が近づきます。移動の判断はUpdate、Rigidbody2Dの移動はFixedUpdateで行い、描画フレーム数による速度差を避けています。

## 上限と負荷

`Assets/Game/Resources/SpellSettings.asset` で変更できます。

| 項目 | 初期値 |
|---|---:|
| ノード数 | 24 |
| ノード深さ | 6 |
| 発動あたり累計弾数 | 48 |
| 弾生成の最大世代 | 3（最初の弾が第1世代） |
| 発動あたり予約・実行イベント | 128 |
| 弾/持続範囲の最大寿命 | 6秒 |
| 配偶子交叉率 | 70% |
| ノード内部・基礎数値の交叉率 | 70%（各対応ノード／基礎数値群ごと） |
| パラメータ変異率 | 15% |
| ノード置換率 | 6% |
| 構造変異率 | 8% |

弾・派生弾・遅延・範囲効果は同じCastSessionを共有します。予算を超えた生成/イベントは追加せず終了します。通常戦闘・プレビュー・通常攻撃も共通の実行基盤と安全制限を使います。

追加の安全弁として、戦場ごとにイベント待ち行列2048、1フレームのイベント処理512、セッション128、弾オブジェクト256、セッションの最大経過60秒を制限します。終了した弾はその場で0.3秒フェードしてプールへ返します。一時停止中はイベント・弾・遅延時間も停止します。戦闘終了/術者消滅で残った処理を停止します。

## 自動命名と通常画面

`Assets/Game/Resources/SpellNameDictionary.asset` に属性語、特徴語と重要度、弾道語、テンプレート、特殊規則を保存します。発現結果だけを解析し、特徴を最大2つ採用します。命名辞書を変更する場合はversionも更新してください。

autoGeneratedName / customName / nameGenerationVersionを保存し、カスタム名を優先表示します。通常画面の「効果・詳細を見る > 魔法名を変更」で24文字以内の名前を保存できます。空欄で自動名に戻します。名前は威力や挙動に影響しません。

通常の画面では生のノード・染色体・遺伝子数値を表示しません。プレビューと効果説明を使い、構造の詳細はEditorのLabで確認します。
