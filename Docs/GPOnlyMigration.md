# 固有魔法のGP方式への統一（2026-10-28）

固有魔法は初期仲間、既存仲間、配合結果、戦闘AI、プレビューのすべてでGP方式を使います。

## 削除した旧実装

- MagicGenomeの固定遺伝子項目、効果リスト、旧継承記録。
- 旧発動方式・発射方式・軌道・効果のenum。
- LegacySpellAdapter、MagicExecutor、MagicExecutionContext、旧Projectile、ProjectileMotion、MagicSupport。
- 固定パラメータの交叉・突然変異、旧魔法用の配合設定とマスター値。
- 戦闘AI・プレビュー・説明文の旧形式用分岐。

MagicGenomeには染色体、発現結果、バージョン、名前を保存します。MagicFactoryはGPの検証・コンパイルのみを行います。BuiltMagicの表示情報はコンパイル結果から作るキャッシュです。通常攻撃も共通の弾プールとCastSessionを使い、物理防御で計算します。

新規の魔法はSpellProgramBuilderから直接ノードの木を構築します。バフには専用のBuffTypeを使います。既存GPデータを壊さないよう、その保存用IDは維持しています。

## 保存データ

- セーブのスキーマは3です。
- 内部の5枠を保持し、ランクに応じた1～5枠を実際に使用します。使用中の枠と対応する遺伝用の枠を同期します。
- 読み込み時は染色体を検証して発現結果を再生成します。
- 旧形式のJSONや破損した魔法は受け付けません。旧形式が残った別のセーブを読み込んだ場合は読み取り専用にし、上書きを防ぎます。実行時に変換したり、ランダムな魔法へ置換したりする機能はありません。

今回の作業では、削除前のコードで現在のローカルセーブに残っていた旧形式JSONを18件、一度だけGPへ変換しました。その後、変換コード自体をゲームから削除しました。現在のセーブは7体・内部35枠・使用可能25枠で、全枠のGP検証が成功しています。個体ID・種族・個体値・レベル・経験値・親IDを変換前と比較し、一致を確認しました。

変換前の元ファイルは [バックアップ](../Backups/GPOnlyMigration/save-before-20261028-094906.json) に保存しています。復元すると旧形式が戻るため、現在のゲームでは読み取り専用になります。

変換は完全な挙動再現ではありません。旧形式だけに存在した貫通・連射・ランダム移動・被ダメージ時発動・確率発動は廃止しました。変換した魔法にもGPの複雑度・MP消費・クールダウン・寿命上限を適用します。

- 実際の戦闘AIによる独立した魔法発動、MP消費、通常攻撃、回復・バフ・8種類の状態異常、分裂・遅延・イベント上限、120秒相当の弾負荷を確認。
