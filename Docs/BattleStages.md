# 常設・ボスラッシュの仮仕様

ホームの「出撃する」から常設とボスラッシュを選びます。どちらにも Easy、Normal、Hard、Very Hard、Hell があります。

ダンジョンに出現する敵とボスの種族は、スライム系・獣系・鳥系・物質系・虫系・植物系から選ばれます。敵タイプに関係なく、現在の難易度に対応するランクの候補を均等に抽選します。強敵・チャレンジボスもこの6系統からSランクを抽選します。曜日限定ボスは曜日ごとに指定された系統です。対象ランクの候補がない場合は、その回の敵を出現させません。PvPの編成にはこの制限を適用しません。

装備を101個以上所持している場合は遠征に出撃できません。所持一覧と仲間が装備中のものを合わせて数え、同じIDは重複して数えません。100個以下なら出撃できます。戦闘中に100個を超えても、その戦闘は続きます。

常設とボスラッシュはプレイヤーランクで解放します。Easy 0、Normal 50、Hard 100、Very Hard 150、Hell 200です。どちらも同じ条件を使い、現在の所持状況から算出するランクを参照します。

| 難易度 | 出現ランク | 敵レベル上限 |
|---|---|---:|
| Easy | F | 30 |
| Normal | E | 60 |
| Hard | D | 90 |
| Very Hard | C | 99 |
| Hell | 進行に応じ F〜B | 99 |

通常の常設は5分生存で成功。Hellは全滅まで続き、30秒ごとにウェーブが進行します。ボスラッシュは第1波1体、第2波2体というように各波のボス数が1体ずつ増え、各波を全滅させると次に進みます。通常難易度は第5波をクリアすると成功。Hellは全滅まで続き、同時出現数は性能保護のため80体が上限です。すべての敵の従来レベルを3倍し、99で制限します。敵のHPと攻撃力は敵レベルに応じて補正し、魔法攻撃力も種族とレベルに基づいて計算します。ボスの基礎HPは1300です。敵の撃破時に通常敵は1%、ボスは10%の確率で卵を獲得でき、孵化した仲間はレベル1・経験値0になります。

ダメージの目安は、魔法の場合「(魔法の威力＋使用者の魔法攻撃力) × ノード等の倍率 × 100 / (100＋対象の魔法防御) × (1−属性耐性)」です。敵から味方へのダメージには難易度補正を掛けます。毒・火傷の継続ダメージにも同じ補正が適用されます。PvPには適用されません。

2026-10-30の初期調整では、Easy / Normal / Hard / Very Hard / Hell の敵ダメージ倍率をそれぞれ 21 / 25 / 50 / 75 / 100%、通常敵HP倍率を 30 / 50 / 75 / 100 / 100%、ボスHP倍率を 40 / 55 / 70 / 85 / 100% とします。倍率は既存のレベル補正後に適用します。例えばEasy・Lv.9のボスHPは、種族パッシブを除いて 1300 × 1.64 × 0.4 = 約853 です。通常敵よりかなり高い耐久です。

常設の開幕は通常敵5体で、基本出現間隔はEasyから順に4.0 / 3.7 / 3.1 / 2.6 / 2.2秒以上で始まり、時間とともに短縮します。有限の常設ステージでは65秒以降にボスが1体出現し、偶然の追加出現はありません。Hellは従来どおり追加ボスが出現します。経験値は通常敵が15＋敵レベル×2、ボスが100＋敵レベル×10で、出撃者間で分配します。

上記の時間、レベル成長、敵補正、ボス数は初期バランスです。Hellの敵ランクはB、レベルは99が上限ですが、ウェーブ数に上限はありません。LAN 対戦は `Docs/LanPvP.md` を参照してください。
