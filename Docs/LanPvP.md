# 通信対戦

NGO（Netcode for GameObjects）と Unity Transport を使った2人用の LAN 対戦です。両者は同じバージョンのゲームと種族データを使用してください。ホストが戦闘と魔法を実行し、参加者に位置、HP、MP、弾の表示、勝敗を送信します。

1. 両方のプレイヤーがホームから「仲間編成」で出撃する仲間を1〜5体選びます。
2. ホームの「通信対戦」を開きます。
3. ホスト側は「部屋を作る」を押し、Windows の `ipconfig` などで確認した LAN の IPv4 アドレスを参加者に伝えます。
4. 参加者はその IPv4 アドレスを入力し、「参加する」を押します。UDP ポートは 55555 です。
5. 接続と編成の交換が完了すると、自動的に戦闘が始まります。相手が全滅したら勝利。制限時間5分に達した場合は生存数、それも同数なら実際に与えたダメージの合計で判定します。両方とも同じなら引き分けです。同時全滅の場合もダメージ合計で判定します。ダメージは防御・耐性・残りHPを反映した実損失を記録し、毒・火傷の継続ダメージも加算します。

対戦による卵、経験値、ステージ解放はありません。切断すると対戦を終了し、結果画面からホームへ戻れます。対戦中は速度変更と一時停止を使用できません。Windows のファイアウォール等が UDP 55555 を遮断している場合は接続できません。

現在の同期はホスト権威のスナップショット方式です。弾の位置と色は再現しますが、ダメージ数値や範囲演出などの細かな視覚効果は参加者に完全には同期されません。インターネット越しの接続、マッチメイキング、暗号化、切断後の再接続は対象外です。
