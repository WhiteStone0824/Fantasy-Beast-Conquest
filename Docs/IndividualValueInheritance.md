# 子の個体値の計算

配合時、10種類の能力それぞれについて独立に次を計算します。

```
平均 μ = (親Aの個体値 + 親Bの個体値) / 2
抽選値 X = μ + σ × Z   （Zは標準正規分布）
子の個体値 = 0～100に制限したXを四捨五入
```

標準偏差σの初期値は10です。例えば親が40と80なら平均60で、抽選値はおよそ68%が50～70、95%が40～80に入ります（整数への丸め前）。親の個体値差によらず、設定したσを使います。

`BreedingRuleDatabase.ivStandardDeviation`をInspectorで調整できます。0は平均値固定、設定範囲は0～100です。使用中のマスターは`Assets/Game/Resources/BreedingRuleDatabase.asset`、データ側のマスターは`Assets/Game/Data/Breeding/BreedingRuleDatabase.asset`です。

境界外の値は再抽選せず0または100に制限します。このため平均が境界に近い場合、制限後の結果は厳密な正規分布ではなく、境界の値が出やすくなります。0.5は上へ丸めます。これは内部の整数値を決める計算で、ゲーム画面の小数点以下切り上げ表示とは別です。

`IndividualValueInheritance`がBox-Muller法で正規乱数を生成します。配合と同じ`System.Random`を受け取り、同じ親・設定・シードから同じ個体値を再現できます。親のデータは変更しません。以前の片親選択と追加突然変異は行いません。

この変更は今後配合する子に適用し、既存個体の個体値は維持します。乱数の使用方法が変わるため、旧バージョンと同じ配合シードでも結果は変わります。

テストでは平均・標準偏差・分布の割合、能力別の平均、丸め、シード再現性、親の不変性、0～100の境界、実際の配合処理への設定反映を確認します。
