# 状態異常

| 状態 | 効果 |
|---|---|
| 毒 | 最大HPの2%のダメージを毎秒与える。10秒間続く。 |
| 火傷 | 最大HPの5%のダメージを毎秒与える。4秒間続く。 |
| 凍結 | 移動と攻撃・魔法を停止する。火属性の直接ダメージを25%多く受け、その攻撃で解除される。 |
| 麻痺 | 移動速度を30%低下させ、通常攻撃・魔法の待機時間が減る速度を50%低下させる。行動は可能。 |
| 睡眠 | 移動と攻撃・魔法を停止する。直接ダメージを受けると解除される。毒・火傷の継続ダメージでは起きない。 |
| 鈍足 | 移動速度とMP自動回復速度を50%低下させ、通常攻撃・魔法の待機時間が減る速度も50%低下させる。麻痺と同時なら移動速度と待機時間回復速度への補正は乗算される。 |
| 沈黙 | 魔法を使用できなくなる。 |
| 呪い | 通常攻撃・魔法の直接ダメージを50%低下させる。毒・火傷の割合ダメージは対象外。 |

毒・火傷以外の持続時間は魔法の遺伝子などによる。PvPの凍結と睡眠は最大2秒で、解除後1秒間は凍結と睡眠を再付与できない。麻痺は行動不能ではないため、このPvP専用制限の対象外。
