# 期間限定ステージ

- 曜日限定ボス：1日5回。日曜から混沌、星界、竜、幻獣、天使、悪魔、深淵系のBランクLv.75ボス1体。制限時間120秒。
- チャレンジボス：回数無制限、プレイヤーランク200で解放。SランクLv.1000ボス1体、制限時間120秒。所持個体のレベル上限99を維持し、敵の能力のみ1000相当に拡張します。
- 1日1回 強敵：SランクLv.99ボス3体。
- 1日1回 経験値：60秒、経験値100倍。
- 1日1回 超・経験値：プレイヤーランク100で解放、60秒、経験値1000倍。
- 1日1回の3種はそれぞれ独立した挑戦回数を持ちます。既存セーブで以前の共通枠を当日使用済みの場合、強敵・経験値の両方を使用済みとして引き継ぎます。超・経験値は未使用として始まります。
- 挑戦回数は出撃時に消費し、端末のローカル日付の0時にリセットします。端末時計の変更への不正防止はありません。ボスが卵を落とす確率は10%です。
