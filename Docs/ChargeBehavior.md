# 通常攻撃の突撃と性格

通常攻撃は短距離を突撃して接触した場合に物理ダメージを与えます。命中、対象の離脱、突撃時間切れの後は、相手から離れる方向に移動してから次の行動を選びます。行動不能中は移動せず、突撃を中断します。突撃や退避中も、行動可能なら固有魔法は自動発動します。

突撃を開始する条件は、その個体のMPが0であることです。フレーム開始時にMPが0なら、同じフレームの自然回復だけで突撃機会を失わないようにします。魔法を発動した場合はその結果を優先します。開始済みの突撃は、その後MPが回復しても最後まで継続します。味方・敵・PvPの両陣営に同じ条件を適用します。

性格マスターの `chargeCooldownMultiplier` は突撃間隔への倍率、`chargeRetreatDistance` は退避距離の目標です。攻撃速度による基本間隔は最低0.7秒で、倍率と速度バフを反映します。退避が終わる前に再突撃しません。退避は移動速度と鈍足の影響を受け、最大1.5秒で終了します。

| 性格 | 突撃間隔倍率 | 退避距離の目標 |
|---|---:|---:|
| 勇敢 | 0.7 | 1.0 |
| 臆病 | 2.6 | 2.0 |
| 冷静 | 1.5 | 1.5 |
| 慎重 | 2.2 | 1.9 |
| 好戦的 | 0.5 | 0.8 |
| 温厚 | 2.0 | 1.7 |

同じ性格で同じ能力なら、間隔は乱数に頼らず同じ規則で決まります。敵の個体やPvPの両陣営にも同じ性格設定を適用します。移動速度、敵の追跡や行動不能のため、実際に確保できる距離や突撃回数は変わります。
