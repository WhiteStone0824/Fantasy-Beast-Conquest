# 種族のデフォルト魔法

全420種族に、内部5枠・合計2,100枠の初期GP魔法を種族マスターへ保存しています。使用枠はF/E=1、D/C=2、B=3、A=4、S=5です。[全種族の使用魔法一覧](SpeciesDefaultMagic.md)を参照してください。

## 魔法の内容

各種族の属性パッシブを優先し、系統・ランク・同系統内の種族差からGPプログラムを作っています。例えばスライムは水弾と鈍足、鳥は複数方向の弾、虫・爬虫類は毒、菌類は胞子状の範囲効果、甲殻は防御支援、竜は爆発、妖精・天使は回復、悪魔・人工生命は吸収が基本です。属性パッシブに対応する種族では、既定の系統属性よりパッシブの属性を優先します。

第1枠は系統の特徴、第2枠は状態異常、第3枠は回復・強化、第4枠は分裂、第5枠は範囲爆発を基本にしています。弾道・弾数・威力・持続などにも種族とランクによる違いがあります。すべて通常のノード構造で、専用の魔法実行スクリプトは使いません。

## 出現・戦闘・捕獲

- 野生個体は、出現時に種族マスターの魔法を複製します。同種族の新規個体は同じ初期遺伝子を持ち、個体値・性格・レベルは別に保持します。
- 敵も共通のSpellExecutorで使用枠を番号順に評価します。各枠のMP・クールダウン・発動条件・対象を確認し、実際にMPを消費して発動します。
- 攻撃魔法はプレイヤー部隊、回復・強化は敵側の部隊を対象にします。敵の支援移動と加速による通常攻撃の頻度にも対応します。
- 出現直後の初回クールダウンは2秒＋枠番号×0.3秒＋0～0.4秒です。その後は魔法本来のクールダウンを使います。
- 通常攻撃も継続します。敵のHP・移動・物理攻撃・防御・MPは従来の敵タイプ／種族補正を維持し、魔法の読み込みで上書きしません。元の敵の魔法攻撃力をそのまま使用します。
- 捕獲後は出現時の5枠をそのまま保存します。仲間入り時に魔法を再抽選しません。配合ではこれらの遺伝子を通常どおり交叉・突然変異させます。
- 既存の所持個体・育てた魔法・配合結果を種族デフォルトで上書きする処理はありません。

## 編集・追加

SpeciesDefinitionの`defaultMagicGenomes`がマスターデータです。ランタイムはコピーを使用し、マスターを書き換えません。

`Fusion Any Monster > Spells > Fill Missing Species Default Magic`で未設定の枠を補完し、全種族一覧を出力できます。設定済みの枠は保持します。通常のプロジェクト初期化で種族を作成する際も、デフォルト魔法を設定します。

新しい系統はSpeciesDefaultMagicCatalogの属性・効果・形式の対応表を追加してください。新しい種族は種族マスターに初期GP遺伝子を設定できます。設定のない一時的な種族データには同じカタログから初期値を生成します。

テストでは全420種族・全5枠の検証とコンパイル、最低個体値・レベル1でも各魔法のMPを確保できること、同種族の初期遺伝子一致、マスターの不変性、敵の攻撃・味方側の回復・Sランクの5枠発動を確認します。

2026-10-28、Unity 6000.4.3f1でEditMode 96/96件・PlayMode 60/60件が成功しました。ビルドは行っていません。[テスト結果](Verification/SpeciesDefaultMagicTests.json)。
