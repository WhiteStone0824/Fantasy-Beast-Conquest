# 装備

仲間ごとに装備を1個付けられます。仲間一覧で個体を選び「3 装備」から、所持品の確認・装備・取り外しを行います。装備中の品は他の仲間に同時には装備できません。

敵を倒すと通常敵は10%、ボスは100%の確率で装備を落とします。ボスの品は良質以上です。装備レベルは倒した敵のレベルに対応し、並・良質・希少・伝説の4段階の希少度があります。6種類（HP、MP、物理攻撃、魔法攻撃、物理防御、魔法防御）から5種類が選ばれ、上昇量もランダムに決まります。数値は装備レベルと希少度で増加します。

装備の補正は割合です。種族値・個体値・レベル・性格から計算した能力値に「1 + 補正率」を掛け、その後に一時補正と種族パッシブを適用します。既存の装備も、保存されたシードとレベルから割合を再計算します。

既存セーブには初回に装備を3個配布します。親を配合で消費する際、親の装備は所持品に戻ります。PvPには装備の情報も送信されます。装備の能力値は固定シードから再現し、セーブデータに保存します。

ドロップ率、希少度、補正量は初期調整値です。装備の売却・強化・ロックは未実装です。
