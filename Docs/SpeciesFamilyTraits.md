# 系統別の得意分野

系統ごとの得意・苦手を各種族の固定された種族値に反映しています。以前の得意能力1.35倍・1.25倍、苦手能力0.9倍は計算済みであり、実行時に重ねて適用しません。種族ごとに得意分野をさらに分け、名前に合う特徴を加えています。パッシブは戦闘時に別途適用されます。[各種族の固定値一覧](SpeciesBaseStats.csv)。

得意属性のダメージ軽減は45～65%、苦手属性は最大8%、得意な状態異常への付与抵抗は45～65%です。パッシブによる補正は戦闘時に別途加算されます。
