# 系統別の得意分野

系統ごとの得意・苦手を各種族の固定された種族値に反映しています。以前の得意能力1.35倍・1.25倍、苦手能力0.9倍は計算済みであり、実行時に重ねて適用しません。種族ごとに得意分野をさらに分け、名前に合う特徴を加えています。パッシブは戦闘時に別途適用されます。[各種族の固定値一覧](SpeciesBaseStats.csv)。

得意属性のダメージ軽減と得意な状態異常への付与抵抗は、ランク補正前で45～65%です。通常種族の基礎耐性にはEからSまでランクごとに5ポイントずつ加算し、上限を80%とします。系統ごとの苦手属性のダメージ軽減は最大8%のままです。属性による状態異常の付与抵抗と、状態異常ごとの付与抵抗にも同じランク補正が入ります。パッシブによる補正は戦闘時に別途加算され、合計は100%を超えません。

真理系の特殊個体は指定どおり、基礎耐性をすべて50%に維持します。種族ごとの元の値にも差があるため、各項目で必ず高ランクが上回るわけではありません。
