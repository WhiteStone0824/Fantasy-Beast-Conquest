# 固有魔法の配合シミュレーション（2026-11-01）

## 条件

- Unity Editor 6000.4.3f1 の実際の `BreedingSystem.Breed`、種族データ、標準魔法、現在の `SpellSemanticAnalyzer` と `SpellViabilityEvaluator` を使用。
- 固定シード `20261101`。親の種族は候補から一様ランダムに選択し、個体値・性格もランダム。各親はその種族の標準魔法5枠を持つ。配合ごとに親を新規作成し、子同士の世代交代は行わない。
- 全種族420種からの1,000配合と、野生出現6系統（スライム・獣・鳥・虫・植物・物質）の全ランクの種族からの1,000配合を別々に実施。野生出現ランクや実際の取得頻度に応じた重み付けはしていない。
- 子は配合処理のとおりレベル1、装備なし。使用可能なスロットのみ集計。5枠のうち未解放枠は除外。
- 条件が合えば成立する魔法を「条件付き」、効果が1つも到達しないものや対象が一致しないものを「無効」とする。最大MP不足は別に集計する。既存の判定器による静的評価であり、戦闘の実効性を保証するものではない。

対象不一致は、ほかに有効な効果も残る魔法を含み、有効・条件付きの内数。標準魔法への代替も最終的な判定の内数であり、代替前の全候補の失敗率そのものではない。

ノード接続の署名にはノードIDや対象を含む。特徴の組み合わせは生成ノードの種類・属性・弾道・対象、および効果種類・状態異常またはバフを集合化して数えた。数値差は特徴数に含めず、到達不能なノードがあっても署名に含まれうる。いずれも「実戦で異なる挙動の種類数」の厳密値ではない。名称数は自動命名上の種類数で、魔法性能の種類数とは異なる。

## 限界と次の確認

実戦シミュレーションは行っていない。敵味方の位置、選択対象、移動、AIの条件、状態異常抵抗、戦闘中のMP回復・競合、威力の有用性は未評価。静的判定に漏れや誤判定がある場合、0件は実際の無効率0%を意味しない。特に効果の一部が不発でも、有効経路が1つあれば全体は有効と判定する。

親が標準魔法の1世代のみなので、長い世代を経た多様性、既存セーブの遺伝子、特殊個体、実際のプレイヤーの配合選択は代表していない。複数世代の配合と戦闘実行を追加し、発動・命中・有効な回復や状態異常の実発生を測る必要がある。

再実行用のUnity MCP `execute_code` 本文は `Docs/MagicSimulation.cs.txt`。野生6系統のみの場合は `wildOnly = true` にする。プレイヤーのセーブは読み書きしない。
