# 系統の到達段階と能力調整

通常遠征の出現系統6種を第1段階とし、前段階までに作れる系統同士の配合結果を次の段階に追加します。同じ世代で新しく追加された系統は、その世代の組み合わせに使いません。各系統の最短到達段階を使います。

| 段階 | 系統 | 種族値の倍率 |
|---|---|---|
| 1 | スライム、獣、鳥、虫、植物、物質 | 1.0 |
| 2 | 爬虫、両生、菌類、巨人、人工生命 | 1.0 |
| 3 | 水棲、甲殻、亜人、鉱物、機械、竜 | 1.2 |
| 4 | 魔導、幻獣、妖精 | 1.3 |
| 5 | 精霊、天使、星界、混沌 | 1.5 |
| 6 | 呪物 | 1.5 |
| 7 | 悪魔、死霊、霊体、影、深淵 | 1.5 |

真理系は通常の系統表ではなく特殊配合で生まれるため、5段階目以降と同じ1.5倍を適用します。種族値10項目に倍率を掛け、耐性とパッシブは変えません。MP回復は、能力計算後の実際の毎秒回復量に全系統共通で0.2倍を適用します。

配合魔法は、新しい子の染色体で生成ノードの対象と効果の対象が矛盾する場合、効果に合う味方・敵の対象へ調整します。発現結果に生成と有効な効果の組み合わせが存在しない場合は、子の種族の同じスロットの標準魔法を代替します。混在する効果のすべてが必ず発動するわけではありません。変更前から所持していた魔法は書き換えません。
