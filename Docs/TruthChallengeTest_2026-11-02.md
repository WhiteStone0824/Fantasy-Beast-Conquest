# 真理系 Lv.99 対チャレンジボス 実戦テスト

2026-11-02にUnity 6000.4.3f1のPlayModeで、実際のBattleシーンとチャレンジボスのステージ設定を使用。真理系1体のみを出撃させた。

- 真理系：最聖 朝原彰晃、Sランク、Lv.99、個体値は全項目50、性格は冷静、装備なし、種族の標準魔法5枠。
- 対戦相手：古代遺跡の番人（物質系・Sランク・Lv.1000）。ステージの通常のランダム選択で出現。乱数シード20261102。
- 戦闘速度3倍。制限時間120秒。元のプレイヤーセーブを使用しない隔離プロジェクトで実施。

## 結果

真理系の敗北。経過ゲーム時間20.19秒で戦闘不能になった。真理系の最大HPは268.20、復活パッシブは1回発動したが、その後再び戦闘不能。ボスのHPは最大132,547.00から97,060.65まで減少し、残り約73.2%。この値は開始時と終了時のHP差であり、回復を含む場合の累計与ダメージではない。

即死はボスの生存中に発動しなかった。1試合のみの結果で、即死・属性相性・個体値・性格・装備・魔法遺伝子・ボス種族によるばらつきや勝率は評価していない。3倍速により通常速度とフレーム・物理更新が異なる可能性がある。隔離プロジェクトではキャラクター画像を省略しているため、画面の描画品質は検証対象外。

実行テスト：`Assets/Tests/PlayMode/TruthChallengePlayModeTests.cs`。PlayModeテスト1件成功。
