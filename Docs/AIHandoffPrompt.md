## 2. ゲームの目的と現在の範囲

Vampire Survivorsに似たサバイバル戦闘に、複数ユニット編成・育成・固有魔法・配合を組み合わせるゲームです。プレイヤーはキャラクターの移動や攻撃を直接操作しません。編成した仲間が独立したAIで索敵・移動・攻撃・回復・支援・回避を行います。

主役は「個体独自の遺伝子魔法」と「魔法の処理構造まで変化する配合」です。単なるサンプルを増やすのではなく、拡張可能なゲームプロジェクトとして開発してください。

現在は最大5体を編成でき、全滅で敗北、120秒生存で勝利する戦闘が実装されています。これは完成品全体の仕様が確定したという意味ではありません。ステージ進行・仲間の継続獲得・報酬経済などの完成状況を推測しないでください。

戦闘中の捕獲による仲間獲得を追加しています。右上「捕獲」で一時停止し、敵をクリックして選択します。初期条件はHP35%以下、成功率40～95%（弱いほど高い、ボスは半分）、1個体に1回、1戦で最大3体。保存成功後に敵を退場させ、所持仲間・図鑑へ反映します。失敗した保存で敵や所持情報を消さないでください。詳細は `Docs/CaptureSystem.md`。一般的な報酬経済・召喚・捕獲アイテムは含みません。

捕獲画面の「手加減して再開」は、対象1体のHPを1残す一時的な保護を設定します。選んだ敵を倒してしまう問題を防ぐための操作です。手加減の解除、捕獲成功・失敗、上限到達、戦闘終了で保護を解除します。通常のダメージ計算は維持し、最後の実ダメージ量だけを制限するため、HP吸収や撃破イベントを誤って増やさないでください。

## 3. 種族・個体・育成

実装済み：30系統×7ランク×各2種＝420種族。各種族に個別のScriptableObject、日本語の種族名、画像、種族値、耐性、行動傾向、種族共通パッシブがあります。

30系統：スライム、獣、鳥、爬虫、両生、水棲、虫、甲殻、植物、菌類、亜人、巨人、物質、鉱物、機械、人工生命、魔導、竜、幻獣、妖精、精霊、天使、悪魔、死霊、霊体、呪物、影、星界、深淵、混沌。

- ランク：F / E / D / C / B / A / S。
- 種族値10項目：HP、MP、物理攻撃、魔法攻撃、物理防御、魔法防御、移動速度、攻撃速度、索敵範囲、MP回復速度。
- 個体値は各項目独立した整数0～100。最初の仕様書にある0～31は変更済みです。戻さないでください。
- 子の個体値は各能力ごとに両親の平均を中心とする正規分布から決定します。標準偏差はBreedingRuleDatabase.ivStandardDeviation（初期値10、0なら平均固定）です。四捨五入し0～100に制限します。片親選択と追加の個体値突然変異は廃止しました。シードで再現でき、既存個体の値は変更しません。
- レベルは1～99。経験値・成長計算・上限到達後の処理があります。
- 性格は勇敢、臆病、冷静、慎重、好戦的、温厚。能力補正とAIに影響します。
- 属性は火・水・風・土・光・闇・無。
- デバフは毒・火傷・凍結・麻痺・睡眠・鈍足・沈黙・呪い。
- 同じ種族の種族値・耐性・パッシブは共通です。個体値・性格・レベル・魔法と混同せず、個体処理でマスターを書き換えないでください。
- 属性ダメージ軽減、属性による状態異常抵抗、デバフ種類ごとの抵抗は別に扱います。

420種すべてにパッシブ名と3つの効果を設定済みです。例：スライム「水の申し子」は水耐性＋50ポイント、水属性与ダメージ＋20%、水魔法消費MP－20%。種族変更・配合後は子の種族のパッシブを使用します。耐性加算の上限は100%。命中時の追加状態異常パッシブは毎秒1回まで判定します。全種族の詳細は `Docs/SpeciesPassives.md` を参照してください。

種族名は自然な日本語の固有の種族名にしてください。ランクだけを付け替えた「王級○○」のような機械的な命名は避けてください。

## 4. 配合の確定ルール

- 異なる2個体を親にします。同じ個体を両方に指定できません。
- 系統の組み合わせは交換可能で、全30系統の対称な465組を明示した表があります。精霊系＋物質系＝魔導系、獣系＋機械系＝人工生命系、天使系＋悪魔系＝混沌系など、第三の系統も生まれます。FamilyBreedingCatalogが既定表、Resources/BreedingRuleDatabase.assetが実際の編集対象です。未設定時もenum番号の小さい親で代用せず既定表を参照します。全一覧は `Docs/BreedingFamilyTable.md`、早見表は `Docs/BreedingFamilyMatrix.csv`。
- 原則として系統・ランクから実在する種族候補を解決します。
- 配合表の重複調整済み：全465通りで各結果系統15～16通り。親の片方を固定した30通りでも結果15～17種類・同じ結果最大5通りです。代表レシピ・同系統の結果・対称性を維持しています。`Tools/balance_family_recipes.py` は関連性を条件とする決定的なオフライン編集用ツールで、ランタイムの抽選ではありません。`Docs/BreedingFamilyBalance.md` を参照してください。
- **同ランク・同系統・別種族の親同士は、子を必ず1ランク上にします。S同士はSです。** この条件では通常の昇降格抽選を行いません。
- この昇格に必要な種族が存在しない場合、下位種族で代用して配合を成立させないでください。
- 個体値は各能力について両親の平均を中心とする正規分布から決めます。標準偏差の初期値10、四捨五入して0～100に制限します。性格には継承とランダム決定があります。
- 乱数シードで配合内容を再現できます。個体IDそのものはGUIDです。
- **成功して保存できたときだけ、親2体を所持一覧と編成から消し、子1体を追加します。** 親が編成中なら子を1枠へ引き継ぎます。
- 保存・配合の失敗時は親・編成・選択を失わないこと。系譜には親IDと世代を残します。
- 配合画面の予測、再抽選、「別の条件を試す」ボタンは廃止済みです。復活させないでください。

## 5. 固有魔法：GP方式のみを使用する

旧形式は削除済みです。MagicGenomeには染色体・発現結果・バージョン・名前だけを保持し、MagicFactoryはGPコンパイルのみを行います。MagicExecutor・旧Projectile・LegacySpellAdapter・旧enumはありません。旧形式を復活させないでください。

初期仲間・既存仲間・配合結果を含め、すべての固有魔法は遺伝的プログラミング方式です。固定の既製スキル一覧から選ぶ方式ではありません。可変長の型付き木構造を継承し、ノード・接続・分岐・部分木自体が変化します。旧形式のパラメータだけを混ぜてGPを実装したと主張しないでください。

### 遺伝子と発現

- 各魔法スロットにChromosomeA/Bという2本の独立したプログラムを保持します。
- 各プログラムにノード、接続、パラメータ、ルート、調節遺伝子があります。循環・ノード共有のない木です。
- GenotypeとPhenotypeを分離します。未発現の染色体も削除しません。
- dominanceの高い染色体を基礎にし、同値ならA。調節遺伝子に従い、もう一方から型互換の部分木を最大1回組み込みます。
- 不正な組み込みは取り消し、基礎構造に戻します。同じ遺伝子型・アルゴリズム版から同じ発現結果を得ます。
- 発現制約のノード数・深さも遺伝子型に保存し、設定変更だけで発現構造が変わらないようにしています。
- 配合では親ごとに2本の染色体から部分木交叉した配偶子を1本作り、子が親A/Bから1本ずつ受け継ぎます。親データは変更しません。
- 両親の配偶子間でノード内部の交叉も行います（SpellParameterCrossover）。同種・同入力型のノードを対応付け、属性・弾道・状態異常などは項目ごとに親から選択、数値は両親の範囲内で混合します。弾数は混合後に整数へ丸めます。基礎威力・基本クールダウン・射程も混合対象です。交叉率はSpellSettings.nodeParameterCrossoverChanceで初期値70%。構造は維持し、不正なら取り消します。保存済みの魔法は変更しません。
- 変異はパラメータ変異、互換ノードへの置換、追加・削除・部分木置換などの構造変異。変更後は必ず検証し、不正なら取り消します。

### スロット

全420種族のSpeciesDefinition.defaultMagicGenomesに初期GP魔法5枠を保存済みです。WildUnitFactoryは種族マスターから複製し、敵も出現時からランクに対応する1～5枠を使用します。野生時に魔法をランダム生成したり潜在情報だけにしたりしません。捕獲後も同じ遺伝子を保持します。既存の所持個体・配合結果は上書きしません。詳細は `Docs/SpeciesDefaultMagicRules.md`、全種族一覧は `Docs/SpeciesDefaultMagic.md`。

内部には常に5枠分の遺伝子を保持します。使用可能数はF/E=1、D/C=2、B=3、A=4、S=5。使用できない枠も保存し、親の対応する番号のスロットから継承します。

- `magicGeneSlots` / `magicSlotGenomeJson`：5枠の内部データ。
- `magicGenomes` / `magicGenomeJson`：使用可能なGP魔法の表示用データ。
- 壊れた枠を読み飛ばして後ろを繰り上げたり、無関係なランダム遺伝子へ置き換えたりしないでください。

### ノードと実行

- 発動：PeriodicTrigger、EnemyNearTrigger、HPThresholdTrigger。
- 生成：SpawnProjectile、SplitProjectile、SpawnArea。
- 効果：Damage、Heal、Explosion、ApplyStatus、Knockback、LifeSteal。
- 制御：Delay、RandomBranch、Conditional。
- 既存支援との接続用にSequence、ApplyBuff、ManaStealもあります。
- 弾道：直進・追尾・螺旋・波状・周回。
- 全8種類の状態異常に対応します。
- イベントはCast / Hit / Expire / Killの型を持ち、Next / OnHit / OnExpire / OnKill / True / Falseなどを通して接続します。
- 発現→検証→コンパイルしてCompiledSpellを生成し、戦闘中は命令配列を共通のSpellExecutorでイベント駆動実行します。毎フレーム・毎発動で遺伝子を再解析しないでください。
- AIは使用可能枠を番号順に独立評価し、MP、個別クールダウン、トリガー、対象、沈黙などを確認します。発動中も原則として移動できます。
- 攻撃は敵、回復・バフは味方が対象です。威力・魔法攻撃・魔法防御・属性耐性・バフ/デバフ・種族パッシブを反映します。

新GPの初期上限：ノード24、深さ6、累計弾48、弾生成3世代、イベント128、弾と持続範囲の寿命6秒。CastSessionで派生処理まで予算を共有します。`SpellSettings.asset` で変更可能です。

追加の安全制限は、戦場ごとに待機イベント2048、1フレームの処理512、セッション128、弾オブジェクト256、セッション最大60秒です。通常戦闘・プレビューともGPの制限に統一済みです。

### 自動命名

発現した構造から主属性・形態・弾道・効果を解析し、重要な特徴を最大2つ採用して日本語名を生成します。辞書と特殊規則は `SpellNameDictionary.asset`。autoGeneratedName / customName / nameGenerationVersionを保存し、カスタム名を優先します。通常画面で24文字以内の名前へ変更可能。名前は性能に影響しません。

## 6. 戦闘・演出

実装済み：複数味方の自動戦闘、時間経過で増える敵、通常・高速・高耐久・遠距離・ボス、ウェーブ、経験値分配、HP/MP、支援、勝敗、ホームへの帰還。

- 戦闘速度は1/2/3倍。一時停止中はMP消費、攻撃、弾、イベント、時間経過を止めます。
- 移動判断はUpdate、Rigidbody2Dの移動はFixedUpdate。短射程の攻撃・支援には接近します。
- 弾は寿命や射程で終了しますが、突然消さず、その場で止まってフェードしてからプールへ戻します。フェードは0.3秒です。「消さない」という以前の要望を無限寿命と解釈しないでください。
- ダメージ、HP/MP回復、状態変化、レベルアップをフローティング文字で表示。上限64、短時間の同種ダメージを合算します。
- HP吸収は実際に与えたダメージを基準にし、親弾のダメージを子弾が使い回してはいけません。
- デバフ中は種類ごとの持続エフェクトを表示します。毒=泡、火傷=炎、凍結=氷、麻痺=稲妻、睡眠=Z、鈍足=足元の輪と矢印、沈黙=封印、呪い=紫の紋章。重複表示・解除・戦闘不能・一時停止に対応します。
- **最大MPの75%へ魔法の消費MPを補正する処理は廃止済みです。** 有効な種族パッシブの割引は適用しますが、最大MPを理由に安くしないでください。

## 7. UIの確定方針

- 日本語、uGUI＋TextMesh Pro。左側の常設メニューは廃止。現状は上部ナビとホームの導線です。
- 戦闘開始はホームの「出撃する」からだけ行えます。
- ホームは編成中のキャラクターの姿が見える構成。以前のワイヤーフレームは配置イメージであり、白黒の図形をそのまま再現する指示ではありません。画像・背景・複数の色を使って分かりやすくしてください。
- 図鑑、編成、配合の親選択、配合結果はキャラクター画像アイコン形式。親枠をクリックすると所持一覧が開きます。
- **魔法図鑑は禁止です。** 固有魔法はその個体に属し、個体詳細から確認します。
- 通常画面に生の遺伝子数値・染色体・継承履歴・突然変異履歴・ノード構造を出しません。Editor用デバッグ画面での表示は許可されています。
- 通常画面には魔法名、属性、基本威力、実際の消費MP、付与デバフ、付与率・持続・効果の説明を表示します。プレビューを中心に置き、詳しい説明は「効果・詳細を見る」へ分けます。
- プレイヤー向け画面に画像ファイル名・パス・生成処理などの開発情報を出しません。
- 設定画面から画像生成機能・ComfyUI接続設定は撤去済みです。
- 表示数値は小数点以下切り上げ。内部計算や保存値まで整数にしないでください。

図鑑：一度でも仲間にした種族だけ通常の名前・画像・詳細を公開し、未入手は黒いシルエットと「???」。未入手の詳細は開けません。入手履歴を保存するため、配合で親が消えても登録は残ります。履歴導入前に失った種族は、過去記録がなく復元できません。

グラフ：図鑑の種族値は全種族共通の尺度で10項目を1列の棒グラフにします。仲間詳細の最終能力値も能力ごとに固定した全キャラ共通尺度の棒グラフとし、隣に0～100の個体値レーダーを表示します。図鑑と仲間詳細の2ページ目は、3分類の耐性を0～100%の共通目盛りで棒グラフ表示します。種族値と最終能力値の尺度や意味を混同しないでください。

## 9. 保存とデータ保護

保存先は `Application.persistentDataPath/fusion_any_monster_save.json`。現行セーブ形式はschemaVersion=2です。旧データを読み込み、新形式で保存できます。将来バージョンや破損データは保護し、読み込めなかったファイルを初期データで上書きしないでください。

個体、編成、経験値、系譜、入手済み種族、5スロットの染色体とパラメータ、調節遺伝子、遺伝子版、自動名・カスタム名を保存します。CompiledSpellは保存しません。

テストで実セーブを使用する場合は元ファイルを退避し、成功・失敗にかかわらず復元してください。配合失敗時に親を消す、破損遺伝子を勝手に正常な別遺伝子へ置換する、未対応枠を詰める処理は禁止です。
