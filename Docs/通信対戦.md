# 通信対戦

同じLAN上の別々のWindows PCで、同じバージョンのゲームを起動します。各PCで対戦させる仲間を編成してください。対戦では各種族を1体まで編成できます。同じ系統でも種族が異なれば編成でき、相手チームと同じ種族を使用することもできます。

1. ホストはホームの「通信対戦」を開き、表示された「自分のIP」を参加者に伝えて「部屋を作る」を押します。
2. 参加者は「通信対戦」を開き、ホストから教えてもらったIPv4アドレスを入力して「参加する」を押します。
3. 接続後、お互いのプレイヤーランクが表示されます。両者が「準備完了」を押すと戦闘が始まります。ポート番号はUDP 55555です。

アドレスが複数表示された場合は、両PCが接続しているネットワークのアドレスを使ってください。接続できない場合は同じネットワークに接続しているか、ホスト側のWindowsファイアウォールがゲームのUDP通信を許可しているか確認してください。異なるネットワーク間ではルーターなどの設定が必要になる場合があります。マッチングサーバーや中継機能はありません。ランクは各端末のセーブから算出して送信する表示値であり、第三者による検証はありません。

直接ダメージは遠征と同じ計算式を使い、対戦専用の倍率や上限はありません。1回の通常回復は対象の最大HPの30%までです。凍結・睡眠は最大2秒で、解除後1秒間はこの2種類を再付与できません。麻痺は行動を止めず、移動と待機時間の回復を遅くします。毒・火傷の継続ダメージ、即死、戦闘不能時の完全復活にはそれぞれ既存の効果を適用します。回復と凍結・睡眠の制限は通信対戦にのみ適用します。

並べ替えは仲間管理と配合時の親選択で「並び」を押して切り替えます。入手順、ランクの高い順・低い順、レベルの高い順・低い順を選択できます。セーブ内の仲間の並びや出撃編成は変更しません。
