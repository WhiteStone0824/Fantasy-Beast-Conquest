# 祖父母による特別な配合

配合する2体の親それぞれについて親A・親Bを調べ、次の4種族が祖父母として各1体ずつそろうと、特別な種族が確定で誕生します。祖父母の並び順と、どちらの親の祖先かは問いません。同一個体を複数の祖父母枠に使うことはできません。

- 終焉を告げる魔神
- 世界の底に棲むもの
- 光を呑むもの
- 彼岸を閉ざすもの

特別な種族は真理系・Sランク、レベル1で誕生します。この特別個体を親にして配合した場合も、相手の種族や親の順序に関係なく、子は必ず同じ真理系の種族になります。個体値、性格、5枠の魔法遺伝子は通常どおり2体の親から生成します。配合では親が消滅し、装備は所持品に戻ります。一般の種族抽選や敵としては出現せず、入手後は図鑑に表示されます。

以前のセーブで、消滅済み祖先の種族が記録されていない場合、その個体を条件判定に利用することはできません。家系図に記録が残っている祖先を使ってください。

## 名前と画像を設定する

1. Unityで `Assets/Game/Resources/SpecialSpecies.asset` を選択します。
2. Inspectorの **Display Name** を任意の種族名に変更します。仮名は「特別な魔物（仮）」です。
3. 用意した画像をAssetsへ取り込み、Texture Typeを **Sprite (2D and UI)** にして、同アセットの **Sprite** に設定します。
4. **Species Id** の `special_four_lineages` は、セーブとレシピの識別に使うため変更しないでください。

名前と画像を設定するまでは仮名・画像なしで表示されます。種族値、耐性、パッシブも同じアセットで編集できます。祖父母の条件は `Assets/Game/Resources/BreedingRuleDatabase.asset` の **Special Recipes** で変更できます。エディタ用の同名データは `Assets/Game/Data/Breeding/BreedingRuleDatabase.asset` です。

## パッシブ「真理の御魂」

すべての能力値が20%上昇します。ダメージを与えた攻撃は毒を2秒付与し、対象の属性・毒抵抗によって付与率が下がります。毒の判定は攻撃者につき毎秒1回です。自身が戦闘不能になった時、戦闘中1度だけ自身と倒れた味方全員をHP・MP全回復、状態異常解除で復活させます。すべての属性ダメージ耐性・属性の状態異常抵抗・状態異常ごとの抵抗は50%です。

セーブ形式はバージョン7です。旧バージョンは読み込めますが、特殊種族を認識できない旧ゲームで新しいセーブを上書きしないよう、旧ゲーム側では書き込み禁止として扱われます。
