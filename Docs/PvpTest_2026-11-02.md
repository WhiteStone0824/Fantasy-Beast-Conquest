# 対戦テスト結果（HP 1.5倍の変更前）

Unity 6000.4.3f1の隔離プロジェクトで、2026-11-02時点の耐性およびダメージ式を使用した。通常速度、Sランク・Lv.99、個体値50、性格は冷静、装備なし、標準魔法5枠。各編成1回ずつで、乱数シードは20261102～20261107。種族の組み合わせは `PvpLevel99Simulation_2026-11-02.md` と `PvpTruthSimulation_2026-11-02.md` を参照。

試合4～6では真理系の復活パッシブがすべて発動した。試合6は時間切れで生存数により判定。これはHP1.5倍の変更前の結果で、変更後の時間や勝率ではない。

通信テスト、戦闘テスト、PvPと遠征の直接ダメージ式の一致を確認するPlayModeテスト3件は全件成功。通信テストは同一PC上のループバックで行い、接続、ランク・編成交換、双方の準備、戦闘状態の送信まで検証。2台のPC間、実際の画面描画、ネットワーク遅延や切断、最後の戦闘結果の両端末への表示は未検証。

戦闘テストはCombatantをPvPモードで直接動作させ、通常のBattleDemoの試合進行・通信・描画を省略している。種族画像は隔離環境から省略。シード数が少ないため勝率や有利不利は結論づけられない。
