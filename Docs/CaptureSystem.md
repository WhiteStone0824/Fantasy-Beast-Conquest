# 戦闘中の捕獲

戦闘画面右上の「捕獲」を押すと戦闘が一時停止します。戦場の敵をクリックすると、画像・名前・レベル・ランク・HP・捕獲成功率を確認できます。「捕獲する」で挑戦し、「再開」またはEscで戦闘へ戻ります。

「手加減して再開」で選んだ敵を捕獲対象にすると、その敵へのダメージはHPを1残すようになります。高火力の味方がいても捕獲の機会を作れます。対象には金色の輪と「手加減中」を表示し、次に捕獲画面を開くと自動選択します。手加減は同時に1体までです。同じ画面の「手加減を解除」で取り消せます。捕獲成功・失敗・捕獲上限到達・戦闘終了でも解除します。

## 初期ルール

- HP35%以下の生きている敵に挑戦できます。味方・死亡済み・他の戦場の敵は対象外です。
- 成功率はHP35%時点で40%、残りHPが0に近づくほど95%へ近づきます。ボスはこの確率の半分です。
- 同じ敵への挑戦は1回です。失敗した敵は戦場に残り、再挑戦できません。
- 1戦で仲間にできる数は最大3体です。失敗は成功数の上限を消費しません。
- 捕獲成功時は撃破扱いにせず、撃破数・撃破経験値を増やしません。敵は行動と当たり判定を停止し、フェードして戦場から離れます。
- 捕獲した仲間はその場でJSON保存し、図鑑の入手履歴にも登録します。戦闘に敗北しても保持します。自動で出撃編成へは加えません。
- 保存失敗時は敵・捕獲枠・所持仲間・図鑑を変更せず、再試行できます。読み取り専用セーブは捕獲を拒否します。

`Assets/Game/Resources/CaptureRules.asset`のInspectorでHP条件・成功率・ボス補正・1戦の上限を調整できます。未配置の場合はCaptureRulesの初期値を使います。

## 個体データ

敵の出現時に個体ID、0～100の個体値、性格、レベルを作り、種族マスターから5枠の初期GP魔法を複製します。捕獲時にこれらを再抽選せず、その個体を所持データへ追加します。種族IDは戦闘中に表示している種族と一致します。同種の別個体も所持できます。

野生時の戦闘能力・行動は既存の敵タイプと経過時間補正を使用し、種族ランクに対応する1～5枠のデフォルト魔法を戦闘中から使用します。回復・強化は敵側の部隊へ作用します。捕獲後の能力値は通常の種族・個体値・性格・レベルの計算を使用します。[種族デフォルト魔法の仕様](SpeciesDefaultMagicRules.md)。

通常の出現種族はFランクから始まり、30秒ごとに上限が1段階上がります。累計勝利3回ごとに開始時の上限も1段階上がり、最大Sです。すべての系統・ランクが揃っている現行マスター向けの仮仕様です。

## 実装

- CaptureRules：変更可能な捕獲ルール。
- CaptureSystem：成功判定と、保存成功後にだけ採用する獲得処理。
- WildUnitFactory：出現時の個体・GP遺伝子生成。
- BattleDemo：敵との照合、挑戦済み管理、捕獲数、退場、戦闘結果への反映。
- BattleCaptureUI：uGUI＋TextMeshProの捕獲画面、敵のクリック選択、選択マーカー、一時停止。

既存の所持個体を書き換える移行処理や、セーブのリセットは行いません。
